## 1. 运行位置与优先级

- Mac 承担编辑、Git 管理和可视化；仿真、CUDA 编译与训练在 SSH 远端运行。
- 用户指定优先 `gpu`，连接不可用时回退 `delltower`。
- 已检查本机直连 `gpu`、`delltower`，也尝试在 `delltower` 上执行 `ssh gpu`。有效的 `gpu` 连接路线仍待确认。
- 每次新的运行工作先检查连接；此前失败不代表永久不可用。连接成功后另查 GPU、工具链、环境与资源。

## 3. 后续执行方式建议

1. 检查首选 gpu 路径并设置连接超时；不可连接则选择 delltower，记录实际主机与回退原因。
2. 确认远端项目目录、编译器、Toolkit、PyTorch 和设备，建立项目隔离环境。
3. 用明确 Git 提交同步代码；若运行未提交改动，记录补丁和 dirty 状态。资产固定版本并校验内容。
4. 保存每次运行的配置、提交、资产版本、后端、随机种子、实际主机、设备及日志。
5. 长任务使用持久会话或作业机制，记录 PID/作业 ID 和日志。SSH 中断后先查询已有作业，避免在另一台机器重复启动。
6. 查看器服务通过 SSH 隧道供本机访问，回放不依赖远端桌面。

目前没有自动回退脚本、同步脚本或查看器服务；远端目录与环境名称尚未确定。
